## Summary

Adds protocol-specific handlers for 5 non-HTTP services that were previously falling back to generic responses. Each handler generates realistic protocol-compliant responses and captures credentials from probing bots.

### New Handlers
| Protocol | File | Features |
|----------|------|----------|
| **Redis** | `manyfaced/handlers/redis_handler.py` | RESP greeting, PING response, AUTH credential capture (plain text + RESP bulk string format) |
| **MongoDB** | `manyfaced/handlers/mongodb_handler.py` | Wire protocol greeting, ismaster response, SASL challenge, auth credential capture |
| **Telnet** | `manyfaced/handlers/telnet_handler.py` | IAC negotiation, login/password prompts, credential capture from user input |
| **RDP** | `manyfaced/handlers/rdp_handler.py` | TPKT/X.224 connection confirm, NLA (Network Level Authentication) challenge with credential capture |
| **VNC** | `manyfaced/handlers/vnc_handler.py` | Version negotiation, security type selection, password authentication challenge |

### Changes
- **`manyfaced/common/status.py`**: Added `UNKNOWN_TELNET`, `UNKNOWN_RDP`, `UNKNOWN_VNC` status codes (3 new constants)
- **`manyfaced/handlers/http_handler.py`**: Updated `_handle_non_http_probe()` to route Redis, MongoDB, Telnet, RDP, VNC probes to their respective handlers instead of generic fallback
- **`test/test_integration/test_protocol_handlers.py`**: 24 integration tests covering all 5 handlers (response generation + credential capture)
- **`test/test_http_handler.py`**: Fixed telnet probe test assertion (was using `UNKNOWN_NON_HTTP`, now uses `UNKNOWN_TELNET`)

### Test Results
- **New protocol handler tests**: 24/24 passing
- **Full suite**: 465/468 passing (3 pre-existing failures unrelated to this change — Windows path unicode escape issues in subprocess-generated test files)
- **Lint/format**: ruff check + format clean

### Bug Fixes During Implementation
1. **Redis RESP parsing**: Regex was matching `\r\n` as whitespace, capturing `$5` (RESP length indicator) as username instead of actual user. Fixed by skipping `$`-prefixed groups.
2. **VNC missing parameter**: `_handle_version_negotiation()` referenced `bot_ip` but didn't accept it as a parameter. Added parameter and updated call site.
3. **Telnet type error**: Handler tried byte operations on string data (from `get_protocol_info()` decoding). Added type-aware conversion.

All changes follow CONTRIBUTING.md workflow: branch off master, ruff clean, tests green.
